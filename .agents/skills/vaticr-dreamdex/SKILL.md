# 🔮 Vaticr — Somnia x DreamDEX Event Contracts Hackathon Skill & Guide

Use this skill whenever working on, reviewing, or developing **Vaticr** — the Autonomous DeAI Headline-to-Contract Factory & DreamDEX Bot Kit Fleet on Somnia.

## 📌 Project Overview & Target
- **Target Event:** Somnia × DreamDEX Event Contracts Hackathon (DoraHacks)
- **Prize Target:** 1st Place ($5,000 USDso Prize Pool Target)
- **Primary Track:** Open Track
- **DreamDEX Stack Integration:** DreamDEX Event Contracts + `dreamdex-bot-kit` + DreamDEX API/SDK
- **Core Tech Stack:** Somnia Testnet + Solidity + TypeScript + Next.js 14 + Python 3.11

## 🏗️ Technical Architecture Rules

### 1. DreamDEX Bot Kit (`dreamdex-bot-kit`)
- Embed `@somnia-chain/dreamdex-bot-kit` to automate market-making, order routing, and YES/NO token liquidity seeding.

### 2. Headline-to-Contract Factory (`agents/scout.py`)
- Parse live Web3/financial news APIs and deploy matching DreamDEX Event Contracts on Somnia testnet in under 10 seconds.

### 3. Autonomous Resolution Agent (`agents/resolver.py`)
- Fetch cryptographically verified news payloads to resolve Event Contracts and distribute payout yields.
